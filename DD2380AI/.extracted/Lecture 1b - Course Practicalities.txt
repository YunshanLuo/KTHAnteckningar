DD2380 Artificial Intelligence
          Course Practicalities
Intended learning outcomes
After passing the course, the student should be able to
    • apply different principles of Artificial Intelligence (AI)
    • choose appropriate tools and implement efficient solutions to problems in AI
    • integrate tools to design computer programs that show different properties that are expected by an intelligent
      system
    • present, analyse, and entitle an own solution to an AI problem
    • reflect on and discuss current social and ethical aspects of AI
in order to be able to
    • draw use of methods of artificial intelligence in analysis, design and implementation of computer programs
    • contribute to design of an intelligent system in both academic and industrial applications.

Programming assignments
• Aim and idea: Get you to work hands-on with the course material


• Each assignment structured into E-D, C, B-A levels
   • Search
   • HMMs
   • RL
• You need to be comfy with Python (prerequisite)
Programming assignments
• Strongly encouraged to be carried out in pairs
• Each assignment is assessed by
    • Kattis: checks whether your implementation passes the required tests
    • Assignment Learning Journal: explains your solution, design choices, limitations, and reflection questions
• Kattis does not directly give the grade
    • It gives the highest-grade range you are eligible for
    • The journal determines the grade within that range
    • https://kth.kattis.com/courses/DD2380/ht26
• Individual oral examination
    • One of Search, HMM, or RL is selected independently for each student
    • You must be able to explain the selected assignment, your code, and your Assignment Learning Journal
    • The oral examination sets your individual maximum LAB2 grade
• Deadline rule
    • Grade A requires all code and Assignment Learning Journals on time
    • If any assignment code or Assignment Learning Journal is late, maximum final LAB2 grade is B
