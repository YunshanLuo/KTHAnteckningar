\section{Denial-of-Service (DoS) Mechanics, Amplification, and Network Defenses}

\subsection{Resource Exhaustion Vectors, Spoofing Asymmetry, and Amplification}
A \term{Denial-of-Service (DoS)} attack targets \term{availability} by exhausting a finite system resource; a \term{Distributed DoS (DDoS)} coordinates many compromised hosts (\term{botnet}). An attack succeeds with limited attacker resources whenever \term{cost asymmetry} holds: $\mathrm{Cost}_{\text{victim}}(\text{req}) \gg \mathrm{Cost}_{\text{attacker}}(\text{req})$.
\begin{compactitem}
  \item \term{Four Resource Exhaustion Vectors:}
  \begin{enumerate}[label=(\arabic*), leftmargin=1.8em]
    \item \term{Bandwidth Exhaustion:} Saturates the victim's upstream network link (e.g., ICMP ping flood, UDP reflection/amplification).
    \item \term{State / Memory Exhaustion:} Fills fixed-size kernel/application tables with fake entries (e.g., TCP \term{SYN flood} filling the half-open connection backlog; forged UDP \code{subscribe} packets exhausting server subscription memory).
    \item \term{Computational (CPU/Disk) Exhaustion:} Forces expensive server-side processing per cheap unauthenticated packet (e.g., replaying signed requests to trigger file malware scans, public-key signature verifications, or $O(N)$ hash searches).
    \item \term{Correctness / Crash Exploitation:} A single malformed packet triggers an unhandled exception, null dereference, or buffer overflow.
  \end{enumerate}
  \item \term{Transport Spoofing Asymmetry (UDP/ICMP vs.\ TCP):}
  \textbf{UDP and ICMP are stateless and connectionless}: an attacker can emit packets with a forged source IP address ($\mathrm{IP}_{\text{src}} := \mathrm{IP}_{\text{victim}}$, \term{IP spoofing}) without verification. \textbf{TCP requires a 3-way handshake} ($\text{SYN} \to \text{SYN-ACK}(\mathrm{ISN}_S) \to \text{ACK}(\mathrm{ISN}_S+1)$): a blind spoofer never receives the $\text{SYN-ACK}$ sent to $\mathrm{IP}_{\text{victim}}$ and cannot complete the handshake to send application data.
  \item \term{Reflection \& Amplification Mechanics:}
  Attacker sends small UDP requests with spoofed source $\mathrm{IP}_{\text{src}} = \mathrm{IP}_{\text{victim}}$ to third-party servers (\term{reflectors}), which send large replies of size $|\text{Reply}| = A \cdot |\text{Req}|$ to the victim (e.g., DNS amplification: $\sim 60\text{ B}$ query $\to 4\text{ KB}$ response, amplification factor $A \approx 60\times$). The reflectors' aggregate bandwidth floods the victim regardless of how small the attacker's own bandwidth is. Similarly, if a protocol sends $E_{K_i}(\mathrm{IP}_i) \concat L$ with cleartext response-size $L$, a MitM or replay attacker modifies $L \to L_{\max}$ to make the server flood client $C_i$.
\end{compactitem}
